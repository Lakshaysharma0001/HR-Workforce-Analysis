This project focuses on analyzing HR data to uncover key insights related to employee demographics, attrition, performance, and organizational trends. An interactive Power BI dashboard was developed to support data-driven HR decision-making by visualizing critical KPIs and patterns.

The goal of this project is to demonstrate practical skills in data analysis, visualization, and business intelligence from a real-world HR analytics perspective.

Objectives

1. Analyze employee data to identify attrition trends

2. Understand workforce distribution by department, role, gender, and experience

3. Track key HR KPIs for strategic planning

4. Enable stakeholders to make data-driven HR decisions
